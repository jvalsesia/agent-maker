agent-maker lets you create custom AI agents, custom reusable skills, and chat with them.

- Agents are personas defined by a name, a preamble and a prompt; each one has its own chat window.
- Skills are reusable instruction bundles you can attach and detach to any agent to extend its behavior (one skill can be shared across many agents). Skills are defined by name, description and instructions.
- Memory keeps full conversation history per agent, surfacing recent turns directly and pulling in older relevant ones by semantic similarity so the agent stays coherent over long conversations.


The intent of agent-maker is to act as an operating system for personal AI. It empowers non-engineers to build sophisticated, long-lasting AI teammates that are uniquely tailored to their specific workflows, all through an intuitive, LEGO-like interface.
